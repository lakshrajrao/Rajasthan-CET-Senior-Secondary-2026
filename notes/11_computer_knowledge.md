# 11. COMPUTER KNOWLEDGE (कंप्यूटर ज्ञान)

## 11.1 Basics — Hardware & Software
| Topic | Tathya |
|---|---|
| **Computer ka janak** | **Charles Babbage** (Analytical Engine); **Ada Lovelace** — pehli programmer |
| **CPU** | Central Processing Unit — **Brain of computer**; ALU + CU + Memory |
| **ALU** | Arithmetic Logic Unit — ganana; **CU (Control Unit)** — niyantran |
| **Input devices** | Keyboard, Mouse, Scanner, Microphone, Joystick, Webcam |
| **Output devices** | Monitor, Printer, Speaker, Plotter, Projector |
| **Memory — Primary** | **RAM** (volatile — band hone par mit jata hai), **ROM** (non-volatile) |
| **Memory — Secondary** | Hard Disk, SSD, Pen Drive, CD/DVD |
| **Memory units** | Bit < Byte (8 bit = 1 Byte) < KB (1024 B) < MB < GB < TB < PB |
| **Software — System** | Operating System (Windows, Linux, macOS); **Software — Application** — MS Word, Excel, Browser |
| **OS ke kaam** | File, memory, process, device prabandhan; **GUI** — Graphical User Interface |

## 11.2 MS Office (in syllabus) & Internet (EXTRA — not in 2026 12th syllabus; 2024 PYQ me HTTP aaya tha, isliye halke me padh sakte ho, priority mat do)
- **MS Word:** .docx; **Excel:** .xlsx — cell = row + column (e.g. B5); Formula = se shuru hoti hai (=SUM(A1:A5)); **PowerPoint:** .pptx — slide.
- **Internet:** **WWW — World Wide Web (Tim Berners-Lee)**; **HTTP/HTTPS** — web protocol; **URL** — address; **IP address** — computer ki pehchan; **Browser** — Chrome, Firefox, Edge.
- **Email:** **SMTP** — bhejne ke liye; **POP3/IMAP** — pane ke liye; **@** — at the rate; **CC** — carbon copy; **BCC** — blind carbon copy.
- **Search Engine:** Google, Bing; **Social media** — X, Facebook, Instagram.
- **Cloud:** Google Drive, OneDrive — online storage.

## 11.3 Number System, Networking, Security (EXTRA — not in 2026 12th syllabus; Graduation-level / general awareness only)
- **Binary:** 0 aur 1; Decimal 10 → Binary **1010**; **Solved PYQ-type:** Decimal 13 = **1101**; Binary 101 = **5**.
- **Network:** **LAN** (chhota — office), **MAN** (shahar), **WAN** (desh/duniya — Internet); **Wi-Fi** — wireless LAN; **Modem** — digital↔analog; **Router** — network jodta hai.
- **Cyber suraksha:** **Virus** — hanikarak program; **Antivirus** — suraksha; **Firewall** — suraksha deewar; **Phishing** — nakli email se dhokha; **Password** — majboot (letters+numbers+symbols); **OTP** — One Time Password.
- **E-Governance (Rajasthan):** **SSO Rajasthan** — Single Sign-On portal; **e-Mitra** — Rajasthan ki e-governance seva; **Jan Aadhaar Yojana** — Rajasthan ka parivar pehchan patra; **RajSampark** — shikayat portal.
- **Digital India (2015):** Bharat sarkar ka digital karyakram; **UPI** — Unified Payments Interface (NPCI); **BHIM, Aadhaar, DigiLocker**.

**Computer high-priority (in syllabus):** Babbage, CPU=Brain, RAM volatile, 1 Byte=8 bit, .docx/.xlsx/.pptx, input/output devices, file system, RAM/ROM. EXTRA (low priority): Binary, LAN/MAN/WAN, Phishing, SSO/e-Mitra, UPI.
