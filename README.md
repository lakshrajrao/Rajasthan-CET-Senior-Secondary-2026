# Rajasthan CET Senior Secondary Level 2026 — Complete Exam Intelligence & Preparation System

**Exam:** 1–3 December 2026 (tentative) · **Authority:** Rajasthan Staff Selection Board (RSSB), Jaipur · **Advt. No. 08/2026** (23 June 2026, amended 25 June 2026)
**Pattern (verified):** 120 questions · 240 marks · 150 minutes · +2 correct · −2/3 wrong · E = 0 · blank = −2/3 · >12 blanks = disqualified

Built 11 November 2026. Preparation window: 20 days, 5–6 hours/day. Notes in Hindi+English mix.

## What is NOT in this repo

Binary files (PDFs, XLSX) could not be pushed through the GitHub snapshot tool, which accepts UTF-8 text only. See `BINARY_FILES_EXCLUDED.md` — every binary is listed, and its content is mirrored in a Markdown file here (00/01/02 for the PDFs; the XLSX data lives in the CSVs).

## Key facts (verified — see audit brief for sources)

- 2026 pattern is **120Q/240 marks/150 min with −1/3 negative marking**. 2022/2024 were 150Q/300/3h with **no** negative marking — do not mix them.
- Official scheme gives **no per-subject question split**; the 50/10/15/15/15/5/10 split is reported/derived only.
- **Public Health has zero PYQ evidence** (new 2026 head). Current Affairs after 11 Nov 2026 is not covered — needs a pre-exam update.
- RSSB live-site check failed 11 Nov 2026 (site timed out); verification rests on the uploaded official extract (SHA-256 in the audit brief).
